# Lunar artwork sources

The lunar surface and elevation maps are from NASA's Scientific Visualization Studio, CGI Moon Kit, by Ernie Wright, using Lunar Reconnaissance Orbiter LROC and LOLA data.

Source page: https://svs.gsfc.nasa.gov/4720/

Original files, downloaded without alteration:

1. `lunar-surface.jpg`: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg
2. `lunar-elevation.jpg`: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/ldem_3_8bit.jpg

The website applies the surface map and a subtle elevation bump to a lit Three.js sphere. Its lighting and placement are artistic; it is not an astronomical simulation. The fallback uses the surface map as a circular CSS background.

Credit: NASA's Scientific Visualization Studio.
